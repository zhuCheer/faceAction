## 1. 背景与目标

### 1.1 背景

本工具的核心用户是三类人：

- **懒人**：躺着/瘫着不想伸手，只想动动脸就能刷抖音。
- **顽梗玩家 / 内容创作者**：拍「面部控电脑」段子、直播演示"不用手"的骚操作，制造节目效果。
- **摸鱼族**：上班/上课偷偷刷抖音时，需要用"脸部是否朝向"自动隐藏画面，防止被同事/老师看到。

他们的共同诉求：**看着屏幕、动动脸，就能刷抖音，且能一键防偷窥。**

### 1.2 目标

开发一款基于普通摄像头的 Windows 桌面应用，提供两个一级功能：

1. **看抖音**：点头/抬头切换上/下一个视频，无需双手。
2. **防偷窥**：开启后持续检测人脸；人脸离开画面自动 `Win+D` 切到桌面，人脸回归自动恢复浏览器/抖音。

### 1.3 核心价值主张

- **零门槛零硬件**：普通摄像头即可，无需鼠标键盘。
- **摸鱼刚需**：一个点头开/关的"防偷窥"，人走画切桌面、人回画恢复抖音。
- **有趣可玩**：天然适合拍"无手刷抖音"的短视频段子。
- **隐私安全**：全部本地离线，画面不上传。

### 1.4 非目标（Scope Out）

- 不再提供通用的无手操作体系：鼠标操作、方向键、滚动翻页、媒体控制、确认/取消等一级功能全部移除。
- 不做多级二级菜单；「防偷窥」无二级功能，只有开/关两个状态。
- 不做云端服务；首版仅 Windows 10/11。

## 3. 功能需求

### 3.1 一级菜单

顶部悬浮菜单仅有两个一级项，用左右摇头切换、点头确认：

| 一级项 | 说明 |
|--------|------|
| 看抖音 | 点头进入，自动打开抖音，点头/抬头切视频 |
| 防偷窥 | 点头切换开/关（无二级菜单） |

### 3.2 功能清单（FR）

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| FR-01 | 摄像头采集 | 读取本地摄像头视频流并实时预览 | P0 |
| FR-02 | 人脸检测 | 检测画面是否有人脸（无人脸时输出 no_face） | P0 |
| FR-03 | 关键点提取 | 提取 MediaPipe FaceMesh 468 点 | P0 |
| FR-04 | 点头识别 | 识别点头（俯仰向下） | P0 |
| FR-05 | 抬头识别 | 识别抬头（俯仰向上） | P0 |
| FR-06 | 摇头识别 | 识别左右摇头（用于菜单切换） | P0 |
| FR-07 | 张嘴识别 | 连续张嘴两次返回选择态 | P0 |
| FR-08 | 指令执行 | 发送方向键、打开浏览器、`Win+D` | P0 |
| FR-09 | 预览窗口 | 实时预览 + 悬浮提示 | P0 |
| FR-10 | 看抖音模式 | 进入即打开抖音；点头→下一条(↓)；抬头→上一条(↑) | P0 |
| FR-11 | 防偷窥 | 点头开/关；开启后无脸自动切桌面、有脸恢复浏览器 | P0 |

### 3.3 动作 → 指令交互模型

不再采用"多行为模态"的扁平体系，只保留两个一级项：

| 状态 | 动作 | 语义 |
|------|------|------|
| 选择态 | 右摇 | 切换到下一项 |
| 选择态 | 左摇 | 切换到上一项 |
| 选择态 | 点头（highlight=看抖音） | 进入看抖音，并打开抖音 |
| 选择态 | 点头（highlight=防偷窥） | 切换防偷窥 开/关 |
| 看抖音态 | 点头 (nod) | 下一条视频（↓） |
| 看抖音态 | 抬头 (nod_up) | 上一条视频（↑） |
| 看抖音态 | 连续张嘴×2 | 返回选择态 |

### 3.4 防偷窥功能详解（FR-11）

- 无二级功能，一级项选中后只有 **开启 / 关闭** 两个状态，**点头切换状态**。
- **开启后持续有效**：与是否在看抖音模式无关，全局生效。
- **无人脸**：检测不到人脸时，触发 `Win+D` 效果切到桌面，避免他人看到正在刷的抖音。
- **重新检测到人脸**：将浏览器恢复（若浏览器尚未启动，则打开浏览器并打开抖音）。
- **与看抖音并存**：进入看抖音菜单后防偷窥继续生效，点头/抬头控制方向键与防偷窥人脸检测同时工作，互不干扰。
- **防抖**：人脸「出现/消失」状态需持续 **500ms** 才被确认为切换，抑制人脸短暂丢失或快速来回导致的界面闪动。

**状态机**

```
enabled(开关) — 独立于菜单选择态
人脸 present/absent 的稳定边沿触发 (带 500ms 防抖)：
  present→absent : 执行 Win+D（切桌面）
  absent→present : 若已打开浏览器 → Win+D（恢复）；否则 → 打开抖音
```

## 4. 系统边界与上下文

```text
[用户脸部] --摄像头--> [采集] --> [人脸检测/关键点]
                                   |
[显示器] <--预览-- [UI] <--识别结果-- [动作识别]
                                   |
                    [防偷窥控制器] --无脸--> Win+D / 有脸--> 恢复
                    [看抖音模式] --点头/抬头--> ↑/↓
```

- 输入：摄像头视频流。
- 输出：系统级键盘事件（Win+D、方向键）、浏览器打开。
- 依赖：Windows API（`SendInput`、`webbrowser`）。

## 5. 验收标准

- [ ] 菜单仅含「看抖音」「防偷窥」两个一级项。
- [ ] 看抖音：点头进入并打开抖音，点头/抬头分别触发 ↓/↑。
- [ ] 防偷窥：点头切换开/关；开启后脸离开画面触发 `Win+D`，脸回归恢复浏览器/打开抖音。
- [ ] 防偷窥开启后，进入看抖音后仍持续生效，与方向键控制并存。
- [ ] `pytest tests/` 全部通过。
